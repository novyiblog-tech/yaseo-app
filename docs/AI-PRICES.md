# Цены проверки в нейросетях

Задача Сергея, 30.09.2026: «проверь цены API других нейросетей».

Одна проверка — вопрос около 60 токенов, ответ около 700 токенов, один поиск по интернету.
Поиск обязателен: ответ модели без поиска не совпадает с тем, что человек видит в продукте.

## 1. Вывод

1. Для ИП в России рабочих пути два: Яндекс и Cloud.ru. OpenAI, Anthropic и Google
   на собственных страницах поддерживаемых стран Россию не называют.
2. Самый дешёвый путь — YandexGPT с инструментом Web Search: 0,5–1,1 ₽ за проверку против
   5,08 ₽ сейчас. Не проверено, совпадает ли его ответ с ответом Алисы.
3. GigaChat и DeepSeek поиска по интернету через API не дают.

## 4. Что проверить до смены источника

1. Прогнать 20 одинаковых запросов через генеративный ответ Search API и через
   YandexGPT + Web Search, сравнить названные сайты. Цена опыта — около 115 ₽.
2. Если списки сайтов расходятся, дешёвая связка отвечает на другой вопрос: «что скажет
   модель с поиском», а не «что покажет Алиса». Тогда в отчёте это два разных раздела.
3. Квота Web Search общая с синхронными запросами Search API: 10 в секунду, 10 000 в час.
