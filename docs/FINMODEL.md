# Финмодель yaSEO

Задача Сергея, 30.09.2026: «собери модель с параметрами и тремя сценариями».

Модель — файл `finmodel/yaseo-finmodel.xlsx`. Собирается скриптом `finmodel/build.py`
из вводных `finmodel/params.py`. Все расчёты в файле — формулы: меняете число на листе
«Параметры», пересчитывается всё остальное.

```bash
/opt/homebrew/bin/python3 finmodel/build.py
```

## Листы

| лист | что на нём |
|---|---|
| Сводка | три сценария рядом: подписчики, выручка, прибыль, яма, месяц выхода в прибыль |
| Параметры | 40 вводных с источником у каждой. Синие числа — вводные, жёлтые — допущения без замера |
| Осторожный, Средний, Смелый | помесячный расчёт на 24 месяца |

## Что модель говорит уже сейчас

1. **Судьбу продукта решает поток и конверсия, а не себестоимость.** API и LLM съедают
   около 15% чека, маржа с подписчика — 2 000–3 000 ₽. Между осторожным и смелым
   сценарием разница в подписчиках больше чем в сто раз при одних и тех же ценах.
2. **Выйти в ноль дёшево.** При рекламе 0 ₽ постоянные расходы со взносами ИП — 11,6 тыс. ₽
   в месяц, их закрывают 6 подписчиков. Осторожный сценарий не выходит в ноль не из-за
   расходов, а потому что 300 посетителей в месяц дают одного подписчика в полгода.
3. **Реклама в среднем сценарии окупается с трудом.** Подписчик из рекламы стоит 31 250 ₽,
   приносит за срок жизни 50 231 ₽, возврат занимает около 12 месяцев. Включать рекламу
   стоит после замера настоящей конверсии на бесплатном потоке.
4. **Смелый сценарий — верхняя граница, а не план.** В нём одновременно лучшие значения
   всех вводных.

## Насколько можно верить вводным

| группа | состояние |
|---|---|
| цены тарифов | назначены по ценам конкурентов, решение владельцев |
| себестоимость API Яндекса | замерена 29.09.2026 по странице тарифов |
| эквайринг, УСН, порог и ставка НДС, сервер, база | прочитаны на официальных страницах 30.09.2026 |
| страховые взносы ИП | из поисковой выдачи, первоисточник не прочитан |
| конверсии и отток | западные исследования в пересказе, российских данных нет |
| поток посетителей, цена посетителя, доля по тарифам, выборка лимитов | допущения, замеряются только бетой |
| объём токенов на текст отчёта | допущение, модель не выбрана |

## Упрощения

- Подписчик оформляется в том же месяце, что и бесплатная проверка.
- Доли тарифов постоянны, переходов между тарифами нет.
- Годовой оплаты и скидок нет.
- Порог НДС проверяется по выручке за последние 12 месяцев, а не за календарный год.
- Налог УСН не уменьшается на страховые взносы, потолок дополнительного взноса не учтён —
  налоговая нагрузка завышена.
- Проверки в нейросетях считаются по 5,08 ₽. Связка «YandexGPT + поиск» стоит 0,5–1,1 ₽,
  но совпадение её ответов с ответами Алисы не проверено.
